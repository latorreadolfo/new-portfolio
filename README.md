## 🚀 Portfolio Project

This is my new portfolio project built with **React**, **React Hooks**, and **Next.js**. It includes advanced features such as:

- 🌍 Language switching (English, Portuguese, Spanish)
- 🎨 Dark/Light theme toggle
- ⚡ Optimized performance with Next.js
- 📱 Fully responsive design

### 🔧 Technologies Used

- React.js
- Next.js
- React Hooks (useState)
- CSS Modules

### 📌 Getting Started

Clone the repository and install dependencies:

```sh
 git clone https://github.com/latorreadolfo/new-porfolio.git
 cd new-portfolio
 npm install
```

Run the development server:

```sh
 npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
